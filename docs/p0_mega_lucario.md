## §1 勝ち筋の仕様（win condition spec）

### 実打点式（全て verified）
- **Mega Brave**: `dmg = 270 + 30·[PPP_this_turn]`（弱点/抵抗前）。プローブ実測 270→PPP有 300。verified。
- **Aura Jab**: `dmg = 130 + 30·[PPP_this_turn]`。**加えて value = 基本{F}を min(3, F_in_discard) 枚 トラッシュ→ベンチ**（ctx22/21, min0=任意）。verified。表示130だが「実効価値」に後続ターンのエネ加速が含まれる。
- **Accelerating Stab**(Riolu): `dmg = 30 + 30·[PPP]`。verified。
- **Hero's Cape**: maxHP +100（340→440）。verified。
- **Gravity Mountain**: Mega Lucario ex は **Stage1** ゆえ非対象（場に出ていても maxHP 340/440 のまま）。verified。

### 主勝ち筋（手順）
1. **T1**: Riolu をアクティブ、可能ならベンチにもう1体 Riolu。基本{F}を手貼り。
2. **自分の第2ターン（ゲームturn 3〜4）**: Riolu→Mega Lucario ex に進化、2枚目の{F}を手貼り→**Mega Brave 270**（PPP併用で300）。※進化した番に攻撃可能・「メガ進化で番終了」制約は本シムに**無し**（verified: 同一ターンに進化＋Mega Brave 実行）。
3. **以降**: Mega Brave は自己ロックで隔ターンしか撃てない（verified: Mega Brave 使用の翌ターンは Aura Jab のみ提示）。ロックの番は **Aura Jab 130 + ベンチへエネ加速**、または**別の Lucario 本体に交代**して Mega Brave を継続。
4. 相手の主要アタッカー/低HPベンチを **Boss's Orders** で引き寄せて 270/300 で毎ターン KO。6枚取る。

### 副勝ち筋 / プランB
- 主砲が組めない/落ちた時: 2体目の Mega Lucario ex（4枚積み）に切替。Aura Jab で溜めたベンチエネ＋Switch でロード済み本体を前に出して継戦。
- 究極の壁プラン: Hero's Cape(440HP)+Rock Fighting Energy(技効果無効)+Wally 全回復 で「落ちない主砲」を維持し、相手が 3プライズ×2=6 を取り切る前にこちらが 6 を取る。

### ドクトリン分岐（決め打ち禁止）
- **A: 単騎交互**（1体で Mega Brave↔Aura Jab を交互）。平均 ~200/turn、3プライズ体は常に1体のみ露出。省エネ・省ポケモン。
- **B: 双塔リレー**（2体ロードし、ロック中の本体を交代しながら **毎ターン 270-300**）。DPS 上限だが 3プライズ体を2体露出＋エネ2倍要求。Aura Jab のベンチ加速はこの布陣を明示的に支援する。
- 判別実験は §JSON `doctrines` に A/B の discriminating metric を記載。

## §2 ルール相互作用の棚卸し

- **エネ進化持ち上がり**: Riolu に貼った{F}は Mega Lucario ex に持ち上がる（verified: T1 Riolu 貼り→T3 進化後 2エネで Mega Brave 可）。→ **下位 Riolu への{F}先貼りは有効**（進化前に溜められる）。
- **Aura Jab の給餌方向**: **アクティブでなくベンチにのみ**エネを置く。アクティブ主砲のエネは手貼り(1/turn)のみが供給源。→ Wally で剥がれたアクティブの再装填は最短2ターン、致命的。
- **ダメージ vs ダメカン配置**: 本デッキの打点は全て通常ダメージ（弱点/抵抗適用）。ダメカン配置効果は無し。
- **型要求 vs 供給**: 全技 [F]/[F][F]、供給は基本{F}10＋Rock Fighting3＝**13枚全て{F}**。**型死ゼロ**。「装填中」判定はエネ数(≥2で Mega Brave)で正しく機能する。
- **1ターン1回制の衝突**: サポートは1枚/turn。**Wally(回復)・Lillie/Carmine(ドロー)・Boss(gust)・Xerosic(手札破壊) が全てサポート枠を奪い合う**。回復したい番はドローもgustも出来ない。
- **デッキアウト地平**: 山掘りが厚い（Lillie 山戻し6ドロー×4, Carmine 5ドロー×3, Ultra -3×4, 各種ボール）。ミル手段は自軍に無いが、Ultra/Carmine の高消費＋自己ロックで試合が長引くと山切れ尾リスク（概算 ~turn 25-30 で山枯渇し得る／unverified な概算）。
- **特殊エネ/スタジアム競合**: Rock Fighting は{F}供給＋技効果無効の純アップ（デメリット無し）。Gravity Mountain は自軍に Stage2 が無いため**自己ダメージ無し**、相手 Stage2（例: Alakazam系）にのみ -30。スタジアム競合は Gravity 2枚のみ。
- **弱点**: Mega Lucario ex は **{P}弱点**。環境トップの Alakazam(Psychic) 相手には壁前提が崩れる（unverified: 倍率はシム未計測、テキスト事実のみ）。

## §3 サイド算術（prize arithmetic）

- **こちらは3プライズ側**: Mega Lucario ex は megaEx=**KO で相手に3枚**。相手は主砲を**2体 KO で即6枚(勝ち)**。こちらは 2プライズ ex 相手なら **3KO**、1プライズ相手なら 6KO 必要。**構造的にサイドレース不利**。
- HP: 340（Cape で440）。環境典型打点 ~200 では **単発 OHKO されにくい**が、{P}弱点デッキや2回殴られると落ちる。「主砲は毎ターン取られる」前提では**ない**が、「2体目を落とされたら負け」前提。
- **チェイン要件**: 毎ターン 270-300 で KO を継続するには、自己ロック対策として **2体目を最低ベンチにロード（保険）** しておく必要（ドクトリンB寄り）。ただし2体露出は3プライズ体を2つ晒す＝防御的にはマイナス。バランス点は§5 tensions。
- 勝利までの必要KO: 対 ex デッキで3KO（Mega Brave 3回 ≈ 3ターン、ただし自己ロックで実質4-5ターン）。→ **自己ロックが実クロックを 1.5倍に伸ばす**のが最大の時間損失。

## §7 敗因仮説と L2 規則候補

### 予想される敗因分布
- **prize レース負け**（最有力）: 3プライズ体×自軍＋自己ロックで実クロックが遅く、相手に2KO先行される。
- **tempo 事故**: Wally 無条件発火でアクティブ主砲のエネ全剥がし→2ターン沈黙（catastrophic, self-inflicted）。
- **combo 喪失**: Carmine/Ultra で 678 や唯一 Riolu を捨てる。
- **deckout 尾**: 掘り過多＋長期化。頻度低だが停止則が無いと顕在化。
- **board 全滅**: ポケモン8枚が prize 落ち偏り＋序盤 KO で干上がる（低頻度）。

### 適用パターン（優先順）
1. 自己害効果の無条件発火 → 盤面状態ゲート（Wally=H1, Carmine=H2, Ultra=H3）。**最優先**。
2. スケール技過小評価 → Aura Jab 実効価値(ベンチ加速)を共有知覚へ（H6）。
3. 主砲KO後に殴れない → 2体目の予備装填(チェイン, 上限1)（H5）。
4. gust が価値を逃す → 実打点/サイド期待でターゲット選択（H8）。
5. 妨害の浪費 → 相手盤面条件で限定（Xerosic=H9, Gravity=H7）。
6. 山切れ → 盤面完成後の掘り停止（H10）。
7. 型死ポケモンを装填扱い → 本デッキは型死ゼロだが「エネ数≥2」で装填判定すれば正（自己ロック中でも装填は真, 但し撃てない点は別管理）。

### L2 要否
catastrophic 級の self-harm（Wally/Carmine）が汎用エンジンの既定と直接衝突するため、**L2 は必要**（少なくとも H1/H2 のゲート実装まで）。全仮説が支持され self-harm が発火しないと確認できれば、以降は L1 較正で足りる可能性あり。
