## §1 勝ち筋の仕様

### 主勝ち筋（copy-turbo）
1. **T1-3**: Zorua をバトル場、進化して **N's Zoroark ex(280)** をバトル場に。ベンチに **コピー源**(N's Zekrom or N's Reshiram) を1体。
2. Zoroark に **基本D×2** を装填（手貼り／N's PP Up でベンチに貼り→N's Plan でバトル場へ移送）。
3. **毎ターン atk403 を撃つ**。表示は0だが実打点は下式。以降チェイン。

### 実打点式（★スケール技・全て verified）
- **293 / atk403（コピー）** — `verified: true`
  ```
  damage = W × maxDisplay(場のベンチN's ポケの全技の表示ダメージ)
     maxDisplay ∈ {20(Zoruaのみ), 70(Zekrom1305), 170(Reshiram421), 250(Zekrom1306)}
     W = 2  (相手が Darkness 弱点; 例: 相手 Munkidori) / それ以外 1
  副作用: コピー元が Zekrom1306(250) の場合 → **次ターン Zoroark は攻撃不可(自己ロック)**
  ```
  probe結果: Zekrom+Reshiram併置で **250**(相手Zekromへ) / **500**(相手Munkidori=D弱点へ)。コスト支払いは **Zoroark自身の D×2 のみ**（コピー元の F,L,L,C は不要 = 型死技を型無視で撃てる）。コピー先は**エンジンが表示最大を自動選択**（プレイヤ選択肢なし＝seed11で常に250）。
- **906 / atk1305** — `verified: true`: 70固定、相手の効果を無視（軽減/耐性貫通）。コスト C,C,C は **D×3で支払可**（Zekromが実際に撃てる唯一の技）。
- **303 / atk420** — `verified: true`: `20 × (攻撃体のダメカン数)`。Zoroark がコピーすると「攻撃体」=Zoroark（seed1で被弾Zoroark→200確認）。ただし**表示0のためエンジンは同居する421(170)を優先**し、通常この技は選ばれない。
- **906/1306, 303/421, 303/420, 112/141** の**自前使用は全て型死**（下§2）。

「育てるべき資源」= **(a) バトル場 Zoroark の D×2**, **(b) 場に最大表示のコピー源(=Zekrom を出せば250)**。

### 副勝ち筋 / プランB
- Zoroark が組めない/落ちた: **Zekrom atk1305(70, D×3)** で細く殴る、または **Reshiram-170コピー**継続。
- **Munkidori Adrena-Brain**(`verified: false` 実発火は未確認・テキスト準拠) でダメカン移送スナイプ＝リーサル補助/自軍延命。
- Budew でアイテムロック→相手のBall/道具を止めテンポ稼ぎ（HP30の壁）。

## §2 ルール相互作用の棚卸し

- **エネは進化で持ち上がる**: Zorua に D を先貼り→Zoroark に持ち上げ可。序盤の装填短縮に有効（先貼り**すべき**）。
- **ダメージ vs ダメカン**: atk403 は通常ダメージ（弱点適用＝×2確認）。Munkidori は**ダメカン移送**（弱点無視）。
- **技コストの型 vs 供給型（型死検査、供給=Darknessのみ）** — `verified: true`:

  | 攻撃 | コスト型 | D×nで払える? | 判定 |
  |------|----------|--------------|------|
  | Zorua 402 | D | ○ | 使用可(20) |
  | **Zoroark 403** | D,D | ○ | **主砲** |
  | Zekrom 1305 | C,C,C | ○(D×3) | 使用可(70) |
  | Zekrom 1306 | F,L,L,C | **×** | 型死(コピー専用) |
  | Reshiram 420/421 | F,L… | **×** | **完全型死・自前攻撃不能** |
  | Munkidori 141 | P,C | **×** | 型死(特性専用) |

  → **自前で殴れるのは Zorua / Zoroark / Zekrom(70) のみ**。Reshiram と Munkidori は**永遠に攻撃できないコピー源/特性要員**。L0 が表示打点でこれらを「アタッカー/装填済み」と誤認する余地が大。
- **1ターン1回制**: サポート1/手貼り1/逃げ1。理想は「手貼りD→(不足なら)N's Plan で移送→403」。N's Plan(サポ) と ドローサポ(Lillie/Pokégear/Cyrano/Boss) は**同ターン競合**（サポ枠1）。

- **ACE SPEC**: Prime Catcher 1枚（gust+自入替）。スタジアム競合: N's Castle は相手にも逃げ0を与える諸刃（相手N'sミラー時のみ）。**特殊エネなし**（基本Dのみ＝支払は単純だが型死技は救えない）。

## §3 サイド算術

- **Zoroark ex**: KO時 **2サイド**。HP280は環境の単発(~200-330)を1発耐える帯。**弱点Grass=Grassデッキに即死**。
- **コピー源/特性要員のサイド価値**: Zekrom/Reshiram/Munkidori/Zorua/Budew は各**1サイド**。ベンチに小型を並べる=**gustで安いサイドを献上**するリスク（Boss/Prime対象）。
- **必要KO数**: 主にexを250/500で割る → 相手が2サイドexなら **3KO**、単サイド主体なら最大6KO。**チェイン要件**: 毎ターン「装填済みZoroark 1体＋場に高表示コピー源(Zekrom)1体」を維持。2体目Zoroark装填が250自己ロック回避の前提（§4/H4）。
- トレード構造: こちらは主砲280が硬く**取られにくい**が、盤面幅を広げると**安サイド流出**で押し切られる。

## §7 敗因仮説と L2 規則候補
